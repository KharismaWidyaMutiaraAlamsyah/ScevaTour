# 🚗 Sceva Tour & Travel - Yogyakarta

Website resmi dan sistem kalkulator pemesanan perjalanan untuk **Sceva Tour & Travel Yogyakarta**.

🔗 **Live Website:** [https://kharismawidyamutiaraalamsyah.github.io/ScevaTour/](https://kharismawidyamutiaraalamsyah.github.io/ScevaTour/)

---

## ✨ Fitur Utama
- **Katalog Sewa Mobil & Paket Tour:** Menampilkan tarif sewa mobil + driver serta 15 pilihan paket wisata Yogyakarta dan sekitarnya.
- **Kalkulator Biaya Dinamis Multi-Hari:** Menghitung total estimasi biaya otomatis berdasarkan rentang tanggal perjalanan dan pilihan paket per hari.
- **Deteksi Surcharge Otomatis:** Menambahkan biaya penjemputan luar kota/bandara (YIA, Solo, Semarang) dan estimasi *overtime* secara *real-time*.
- **Kalkulasi DP & Pelunasan:** Menghitung otomatis nominal DP 30% dan sisa pelunasan pada hari H.
- **Integrasi WhatsApp API:** Mengirimkan format detail pemesanan, *itinerary* per hari, titik *drop-off*, rincian biaya, serta nomor rekening resmi langsung ke WhatsApp admin.

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **Tailwind CSS** (CDN)
- **Vanilla JavaScript**
- **Lucide Icons**
